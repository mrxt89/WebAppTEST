## 📖 Convenzioni e Terminologia

### 🔤 Termini Che Incontrerai Spesso

| Termine | Significato | Esempio Visivo |
|---------|-------------|----------------|
| **Menu** | Barra di navigazione principale in alto | Progetti, Attività, Tempi, ecc. |
| **Tab/Scheda** | Sezioni cliccabili dentro una pagina | Overview, Attività, Documenti |
| **Griglia/Tabella** | Lista di elementi in formato righe e colonne | Lista progetti, Lista attività |
| **Card** | Riquadro colorato con informazioni raggruppate | Card statistiche, Card KPI |
| **Badge** | Etichetta piccola e colorata per lo stato | "In Corso", "Completato", "Urgente" |
| **Dialog/Modale** | Finestra popup che appare sopra la pagina | Form per creare progetto |
| **Breadcrumb** | Percorso di navigazione in alto (es. Home > Progetti > Dettaglio) | Ti mostra dove ti trovi |
| **Drawer/Pannello** | Pannello laterale che scorre da destra/sinistra | Dettagli attività, Filtri |
| **Dropdown** | Menu a tendina per selezionare opzioni | Selezione cliente, Stato attività |
| **Toggle** | Interruttore on/off | Attiva/Disattiva notifiche |

### ❓ FAQ - Domande Frequenti

<details>
<summary><strong>Come faccio a trovare velocemente un progetto?</strong></summary>

Usa la **barra di ricerca** nella dashboard progetti. Puoi cercare per:
- Nome progetto
- Codice progetto
- Nome cliente
- Categoria

Oppure usa i **filtri** per raffinare i risultati. Vedi [Gestione Progetti](01_Gestione_Progetti.md#filtri-e-ricerca).
</details>

<details>
<summary><strong>Non vedo il pulsante per creare un nuovo progetto/attività. Perché?</strong></summary>

Probabilmente **non hai i permessi necessari**. Solo gli utenti con ruolo di Responsabile o Amministratore possono creare progetti. Contatta il tuo amministratore per richiedere i permessi.
</details>

<details>
<summary><strong>Come posso modificare un progetto già creato?</strong></summary>

1. Apri la **Dashboard Progetti**
2. Clicca sul progetto che vuoi modificare
3. Clicca l'icona **matita/modifica** (in alto a destra)
4. Modifica i campi desiderati
5. Clicca **Salva**

Dettagli completi in [Gestione Progetti](01_Gestione_Progetti.md#modifica-di-un-progetto).
</details>

<details>
<summary><strong>Come registro le ore che ho lavorato?</strong></summary>

Vai alla sezione **Timesheet** e segui questi passi:
1. Seleziona la settimana
2. Clicca sulla cella del giorno e attività
3. Inserisci le ore
4. Salva

Guida completa: [Gestione Tempi](04_Gestione_Tempi_Timesheet.md#registrazione-ore).
</details>

<details>
<summary><strong>Posso caricare più file contemporaneamente?</strong></summary>

**Sì!** Nel modulo allegati puoi selezionare multipli file tenendo premuto CTRL (o CMD su Mac) oppure trascinare più file insieme nell'area di drop. Vedi [Gestione Allegati](05_Gestione_Allegati_Documenti.md#caricamento-di-nuovi-allegati).
</details>

<details>
<summary><strong>Come faccio a esportare un report dei costi?</strong></summary>

1. Apri il progetto
2. Vai alla scheda **Analytics**
3. Seleziona il tab **Costi**
4. Clicca **Esporta CSV**

Il file viene scaricato automaticamente. Dettagli in [Analytics](07_Analytics_Report.md#report-e-esportazione).
</details>

<details>
<summary><strong>Cosa significa "BOM"?</strong></summary>

**BOM** sta per "Bill of Materials" (Distinta Base in italiano). È l'elenco gerarchico di tutti i componenti, sottoassiemi e materie prime necessari per realizzare un prodotto. Approfondisci in [Gestione Articoli](03_Gestione_Articoli_Distinte_Base.md).
</details>

<details>
<summary><strong>I miei dati sono al sicuro?</strong></summary>

**Sì.** La webapp implementa:
- Autenticazione sicura
- Permessi granulari per utente
- Backup automatici regolari
- Crittografia dei dati sensibili

Ricorda sempre di fare **logout** quando hai finito!
</details>

### 💾 Backup e Sicurezza dei Dati

**Best practice per proteggere i tuoi dati:**

1. **Esporta regolarmente**
   - Report importanti in CSV/PDF
   - Backup delle BOM critiche
   - Lista progetti e attività

2. **Mantieni copie locali**
   - Documenti critici
   - Specifiche tecniche
   - Accordi con clienti

3. **Verifica prima di operazioni importanti**
   - Esporta i dati prima di modifiche massive
   - Controlla di avere backup recenti
   - Testa le operazioni su dati di test se possibile

> **💡 Consiglio**: Crea una routine settimanale di backup dei dati più critici!
