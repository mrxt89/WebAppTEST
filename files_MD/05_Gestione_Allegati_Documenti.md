# Gestione Allegati e Documenti

## Panoramica
La sezione **Gestione Allegati e Documenti** ti permette di caricare, organizzare e condividere file e documenti associati ai progetti, attività e articoli. È essenziale per mantenere tutti i documenti del progetto organizzati e accessibili.

## Accesso alla Sezione
- Dalla **Dashboard Progetti**, seleziona un progetto
- Vai alla **scheda "Allegati"** nel pannello dettagli progetto
- Oppure dalla **scheda "Articoli"**, seleziona un articolo e vai alla **sottoscheda "Allegati"**
- Per le attività, apri i **dettagli attività** e vai alla **scheda "Allegati"**

## Interfaccia Principale

### Layout del Pannello Allegati
La schermata è organizzata in:

**Barra Superiore**
- **Tasto "Carica"**: Per aggiungere nuovi allegati
- **Tasto "Scarica tutti"**: Per scaricare tutti gli allegati in un ZIP
- **Contatore allegati**: Mostra il numero totale di allegati
- **Tasto aggiorna**: Per ricaricare la lista

**Area Filtri**
- **Filtri per tipo**: Pubblici, Visibili, ERP/Temporanei
- **Filtro per categoria**: Seleziona categoria specifica
- **Tasto "Reset"**: Pulisce tutti i filtri

**Lista Allegati**
- **Vista a lista** con dettagli di ogni file
- **Icone per tipo file** (PDF, Word, Excel, etc.)
- **Azioni rapide** per ogni allegato

## Caricamento di Nuovi Allegati

### Passo 1: Aprire l'Uploader
- Clicca il tasto **"Carica"** nella barra superiore
- Si apre una **finestra modale** con l'uploader

### Passo 2: Selezionare i File
**Metodi di selezione:**
- **Drag & Drop**: Trascina i file nella zona di caricamento
- **Tasto "Scegli file"**: Apri il browser file del sistema
- **Selezione multipla**: Puoi caricare più file contemporaneamente

### Passo 3: Configurare i File
**Per ogni file:**
- **Nome file**: Modifica se necessario
- **Descrizione**: Aggiungi una descrizione dettagliata
- **Categoria**: Seleziona una categoria (opzionale)
- **Tag**: Aggiungi tag separati da virgola
- **Visibilità**: Pubblico (visibile a tutti) o Privato
- **Tipo**: ERP (da sistema esterno) o Temporaneo

### Passo 4: Caricare
- Clicca **"Carica"** per iniziare l'upload
- **Barra di progresso** mostra l'avanzamento
- **Notifica** conferma il completamento

## Visualizzazione e Navigazione

### Vista Lista Allegati
Ogni allegato mostra:
- **Icona tipo file**: Colore diverso per ogni tipo
- **Nome file**: Titolo cliccabile
- **Descrizione**: Se presente
- **Informazioni file**: Dimensione, data caricamento, caricato da
- **Badge**: Pubblico, ERP, Nascosto
- **Tag**: Etichette colorate per categorizzazione

### Indicatori Visivi
**Badge e Icone:**
- **Icona globo**: Allegato pubblico
- **Badge "ERP"**: File importato da sistema ERP
- **Badge "Nascosto"**: File eliminato (soft delete)
- **Icone colore**: Diversi colori per tipo file (PDF=rosso, Word=blu, etc.)

### Azioni Rapide
**Per ogni allegato:**
- **Icona download**: Scarica il file
- **Icona occhio**: Visualizza anteprima
- **Menu tre punti**: Azioni avanzate

## Gestione Allegati

### Menu Contestuale (Tre Punti)
**Azioni disponibili:**
- **Dettagli**: Visualizza informazioni complete
- **Visualizza**: Anteprima del file
- **Scarica**: Download del file
- **Versioni**: Gestisci versioni del file
- **Condividi**: Configura condivisione
- **Gestisci categorie**: Assegna categorie
- **Modifica**: Modifica metadati (solo proprietario)
- **Elimina**: Rimuovi allegato (solo proprietario)

### Modifica Metadati
1. **Clicca** "Modifica" dal menu contestuale
2. **Modifica** i campi desiderati:
   - Nome file
   - Descrizione
   - Categoria
   - Tag
   - Visibilità
3. **Salva** le modifiche

### Eliminazione Allegati
1. **Clicca** "Elimina" dal menu contestuale
2. **Conferma** l'eliminazione
3. L'allegato viene **nascosto** (soft delete)
4. Può essere **ripristinato** successivamente

## Filtri e Ricerca

### Filtri Disponibili
**Filtro Pubblici:**
- **Attivo**: Mostra solo allegati pubblici
- **Disattivo**: Mostra tutti gli allegati

**Filtro Visibili:**
- **Attivo**: Nasconde allegati eliminati
- **Disattivo**: Mostra anche allegati nascosti

**Filtro Tipo:**
- **Tutti**: Tutti gli allegati
- **ERP**: Solo allegati da sistema ERP
- **Temporanei**: Solo allegati caricati manualmente

**Filtro Categoria:**
- **Tutte le categorie**: Nessun filtro
- **Categoria specifica**: Solo allegati di quella categoria

### Combinazione Filtri
- Puoi **combinare più filtri** contemporaneamente
- I filtri si applicano in tempo reale
- **Tasto "Reset"** pulisce tutti i filtri

## Gestione Versioni

### Visualizzare Versioni
1. **Clicca** "Versioni" dal menu contestuale
2. **Vedi** tutte le versioni del file
3. **Scarica** versioni specifiche
4. **Confronta** differenze tra versioni

### Caricare Nuova Versione
1. **Apri** il dialog versioni
2. **Clicca** "Nuova versione"
3. **Seleziona** il nuovo file
4. **Aggiungi** note sulla versione
5. **Carica** la nuova versione

## Condivisione Allegati

### Configurare Condivisione
1. **Clicca** "Condividi" dal menu contestuale
2. **Seleziona** utenti o gruppi
3. **Imposta** permessi (Lettura, Scrittura)
4. **Salva** la configurazione

### Tipi di Condivisione
- **Pubblico**: Visibile a tutti gli utenti
- **Privato**: Solo per utenti specifici
- **Gruppo**: Condiviso con gruppi di lavoro

## Categorie e Tag

### Gestione Categorie
**Creare categorie:**
1. **Clicca** "Gestisci categorie" dal menu
2. **Aggiungi** nuove categorie
3. **Assegna** categorie agli allegati

**Categorie predefinite:**
- **Disegni tecnici**: DWG, DXF, STEP
- **Documentazione**: PDF, Word
- **Immagini**: JPG, PNG, GIF
- **Fogli di calcolo**: Excel, CSV
- **Presentazioni**: PowerPoint

### Utilizzo Tag
- **Separati da virgola**: tag1, tag2, tag3
- **Ricerca rapida**: Filtra per tag specifici
- **Organizzazione**: Raggruppa allegati correlati

## Download e Esportazione

### Download Singolo
- **Clicca** l'icona download
- **File** viene scaricato immediatamente
- **Nome originale** mantenuto

### Download Multiplo
- **Tasto "Scarica tutti"**: Scarica tutti gli allegati in ZIP
- **Selezione multipla**: Seleziona allegati specifici
- **Download selezionati**: Solo i file selezionati

### Anteprima File
- **Clicca** l'icona occhio
- **Visualizza** il file nel browser
- **Supporta**: PDF, immagini, documenti Office

## Esempi Pratici

### Esempio 1: Caricare Disegno Tecnico
1. **"Carica"** → Seleziona file DWG
2. **Nome**: "Disegno_Assieme_Motore_v1.0"
3. **Descrizione**: "Disegno di assieme del motore elettrico"
4. **Categoria**: "Disegni tecnici"
5. **Tag**: "motore, assieme, v1.0"
6. **Visibilità**: Privato
7. **Carica**

### Esempio 2: Organizzare Documentazione Progetto
1. **Crea categorie**: "Specifiche", "Manuali", "Certificati"
2. **Carica file** nelle categorie appropriate
3. **Aggiungi tag** per ricerca rapida
4. **Condividi** con il team del progetto

### Esempio 3: Gestire Versioni Documento
1. **Carica** "Specifica_Prodotto_v1.0.pdf"
2. **Modifica** il documento
3. **Carica** "Specifica_Prodotto_v1.1.pdf" come nuova versione
4. **Aggiungi note**: "Corretti errori sezione 3.2"
5. **Mantieni** tutte le versioni per tracciabilità

### Esempio 4: Condividere con Cliente
1. **Seleziona** allegati da condividere
2. **Clicca** "Condividi"
3. **Aggiungi** utenti del cliente
4. **Imposta** permessi "Solo lettura"
5. **Invia** notifica di condivisione

## Regole e Limitazioni

### Permessi Utente
- **Utente Standard**: Può caricare e gestire i propri allegati
- **Responsabile Progetto**: Può gestire tutti gli allegati del progetto
- **Amministratore**: Accesso completo a tutti gli allegati

### Limitazioni Tecniche
- **Dimensione massima**: 50MB per file
- **Tipi supportati**: Tutti i tipi di file
- **Numero massimo**: 1000 allegati per progetto
- **Spazio totale**: 10GB per progetto

### Regole Business
- **Allegati ERP**: Non possono essere modificati
- **Eliminazione**: Solo soft delete (recuperabile)
- **Condivisione**: Richiede permessi appropriati
- **Versioni**: Massimo 10 versioni per file

### Limitazioni di Sicurezza
- **File eseguibili**: Bloccati per sicurezza
- **Virus scan**: Tutti i file vengono scansionati
- **Accesso**: Solo utenti autorizzati
- **Audit**: Tutte le azioni vengono registrate

## Risoluzione Problemi Comuni

### Problema: "File troppo grande"
**Soluzione**: Comprimi il file o dividilo in parti più piccole. Limite massimo 50MB.

### Problema: "Tipo file non supportato"
**Soluzione**: Tutti i tipi di file sono supportati. Verifica che il file non sia corrotto.

### Problema: "Non posso modificare l'allegato"
**Soluzione**: Solo il proprietario o l'amministratore può modificare gli allegati.

### Problema: "Non vedo l'allegato"
**Soluzione**: Controlla i filtri attivi e verifica i permessi di accesso.

### Problema: "Download non funziona"
**Soluzione**: Verifica la connessione internet e riprova. Controlla i permessi del file.

## Suggerimenti per l'Uso Efficace

1. **Usa nomi descrittivi** per i file
2. **Aggiungi sempre una descrizione** dettagliata
3. **Organizza con categorie** e tag
4. **Mantieni versioni** per tracciabilità
5. **Condividi appropriatamente** con il team
6. **Pulisci regolarmente** i file obsoleti
7. **Usa i filtri** per trovare rapidamente i file
8. **Backup importante** per file critici
9. **Documenta** le modifiche nelle versioni
10. **Rispetta** le limitazioni di dimensione
