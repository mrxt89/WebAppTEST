=====================================
WebApp Local Agent - Windows
=====================================

Versione: 1.0.0
Data rilascio: 2025-10-29

REQUISITI:
- Windows 10/11 (64-bit)
- Connessione alla rete aziendale
- Diritti di amministratore per l'installazione

INSTALLAZIONE:
1. Estrarre il file WebApp-Local-Agent-Setup.7z
2. Entrare nella cartella estratta
3. Eseguire "WebApp Local Agent.exe" come Amministratore
4. L'agent apparirà nel system tray (icona in basso a destra)

UTILIZZO:
- L'agent si avvia automaticamente con Windows
- Clic sull'icona nel system tray per vedere lo stato
- Porta predefinita: 7865
- Assicurarsi che la porta non sia bloccata dal firewall

PROBLEMI COMUNI:
- Se l'agent risulta offline nella webapp, verificare:
  * Che l'agent sia in esecuzione (icona nel system tray)
  * Che non ci siano altri agent in esecuzione
  * Provare a riavviare l'agent

SUPPORTO:
Per assistenza contattare l'amministratore di sistema.
